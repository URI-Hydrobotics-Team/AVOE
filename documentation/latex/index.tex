The \textquotesingle{}test()\textquotesingle{} function should be the only place where hardcoded elements are permitted. Also handles command line arguments.\hypertarget{index_autotoc_md5}{}\doxysubsection{\texorpdfstring{Motors and Sensors}{Motors and Sensors}}\label{index_autotoc_md5}
There are two classes {\ttfamily \doxylink{classsensor__t}{sensor\+\_\+t}} and {\ttfamily \doxylink{classmotor__t}{motor\+\_\+t}}, each of these classes contain properties and values for sensors and motors. They directly interface with the drivers through the {\ttfamily \doxylink{vehicle__setup_8h_source}{vehicle\+\_\+setup.\+h}} header file (formally {\ttfamily sensors.\+h} and {\ttfamily motors.\+h}). The {\ttfamily \doxylink{classsensor__t}{sensor\+\_\+t}} and {\ttfamily \doxylink{classmotor__t}{motor\+\_\+t}} objects then interface with other compontents such as the controller or the networking stack. ~\newline
 Sensor and Motor specific "{}middleware"{} exists in the {\ttfamily /\+plugins/\+general-\/\texorpdfstring{$\ast$}{*}} directory.\hypertarget{index_autotoc_md6}{}\doxysubsection{\texorpdfstring{Message system and networking}{Message system and networking}}\label{index_autotoc_md6}
